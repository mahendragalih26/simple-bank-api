# Simple Bank API

A backend banking service written in Go. It models bank accounts, balance entries, and money transfers on PostgreSQL, with type-safe SQL generated by [sqlc](https://sqlc.dev/) and schema changes managed by [golang-migrate](https://github.com/golang-migrate/migrate).

This project is early-stage: the database layer (schema, queries, generated code) is in place; the HTTP API and application entrypoint are still stubs.

## Features (current)

- PostgreSQL schema for **accounts**, **entries**, and **transfers**
- CRUD-oriented account queries (create, get, list, update)
- Docker-based local Postgres
- Makefile helpers for DB lifecycle, migrations, and sqlc generation
- Unit/integration test scaffolding for account operations

### Data model

```
accounts ──┬── entries   (money in/out per account)
           └── transfers (money moved between accounts)
```

- **accounts** — owner, balance, currency
- **entries** — ledger rows for an account (amount may be positive or negative)
- **transfers** — record of a move from one account to another (amount must be positive)

## Install & run

### 1. Clone and enter the project

```bash
git clone <your-repo-url>
cd simplebank
```

### 2. Download Go dependencies

```bash
go mod download
```

### 3. Start PostgreSQL

```bash
make postgres
```

This starts a container named `postgres18` on port **5435** with:

| Setting | Value |
|---------|-------|
| User | `root` |
| Password | `secret` |
| Image | `postgres:18-alpine` |

### 4. Create the database

```bash
make createdb
```

Creates database `simple_bank` inside the container.

### 5. Run migrations

```bash
make migrateup
```

Applies schema from `db/migration/`.

Connection string used by the Makefile:

```
postgresql://root:secret@localhost:5435/simple_bank?sslmode=disable
```

### 6. Generate sqlc code (optional)

After changing SQL under `db/query/` or migrations:

```bash
make sqlc
```

Generated files land in `db/sqlc/`.

### 7. Run the application

```bash
go run main.go
```

Currently prints `Hello, World!` — the HTTP/API layer is not implemented yet.

## Makefile commands

| Command | Description |
|---------|-------------|
| `make postgres` | Start Postgres 18 in Docker |
| `make createdb` | Create `simple_bank` database |
| `make dropdb` | Drop `simple_bank` database |
| `make migrateup` | Apply all up migrations |
| `make migratedown` | Roll back migrations |
| `make sqlc` | Regenerate Go code from SQL |

## Tests

Account DB tests live in `db/sqlc/`. With Postgres running and migrations applied:

```bash
go test ./db/sqlc/ -v
```

> **Note:** Some test helpers (`Store`, config loading, delete query, currency constants) are still being wired up. Align generated queries/package names with the tests before expecting a green suite.

## Development workflow

1. Edit schema in `db/migration/` (new numbered migration files).
2. Write or update queries in `db/query/*.sql`.
3. Run `make migrateup` (or `migratedown` then `migrateup` while iterating).
4. Run `make sqlc` to regenerate Go types and query methods.
5. Use generated APIs from `db/sqlc` in application code and tests.

### Example account queries (`db/query/account.sql`)

- `CreatedAccount` — insert account, return row
- `GetAccount` — fetch by id
- `ListAccounts` — paginated list
- `UpdateAccount` — update balance
